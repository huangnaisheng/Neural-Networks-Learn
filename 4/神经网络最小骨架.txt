============================================================
第四讲之后：神经网络的最小骨架
============================================================

这份文件只记一件事：一个神经网络"最少需要哪几行"。
第四讲后半段那一大坨代码，剥掉所有可选细节之后，剩下就是这些。

判断自己是否真懂的標準：打开一个空文件，不看这份文件，
把这几个类重新写一遍，然后训练到 loss 下降。

------------------------------------------------------------
一、一个"层"必须提供三个方法
------------------------------------------------------------

    def __init__(self, ...):     # 准备参数
    def __call__(self, x):       # 算前向，顺便把结果存进 self.out
    def parameters(self):        # 报告"我有哪些参数需要训练"

就这三条。PyTorch 的 nn.Module 也是这三条，
只是 __call__ 在那边叫 forward (PyTorch 内部帮它接上 __call__)。

self.out 存下来是有用的：训练完可以拿 layer.out 画激活直方图做诊断。


------------------------------------------------------------
二、三种层，每种核心只有一句数学
------------------------------------------------------------

    Linear        x @ W
    BatchNorm1d   (x - 均值) / 标准差 * gamma + beta
    Tanh          torch.tanh(x)


------------------------------------------------------------
三、完整骨架（可直接运行）
------------------------------------------------------------

import torch
import torch.nn.functional as F

g = torch.Generator().manual_seed(2147483647)


class Linear:
    def __init__(self, fan_in, fan_out):
        # 除以 sqrt(fan_in)：抵消 fan_in 项相加带来的尺度放大，纯数学必然
        self.W = torch.randn((fan_in, fan_out), generator=g) / fan_in ** 0.5

    def __call__(self, x):
        self.out = x @ self.W
        return self.out

    def parameters(self):
        return [self.W]


class BatchNorm1d:
    def __init__(self, dim):
        self.g = torch.ones(dim)      # gamma，初始 1
        self.b = torch.zeros(dim)     # beta，初始 0

    def __call__(self, x):
        mu = x.mean(0, keepdim=True)      # 沿 batch 维求平均，每个特征一个
        var = x.var(0, keepdim=True)
        # 1e-5 是防除零；归一化把尺度钉死，gamma/beta 再把自由度还回去
        self.out = self.g * (x - mu) / torch.sqrt(var + 1e-5) + self.b
        return self.out

    def parameters(self):
        return [self.g, self.b]


class Tanh:
    def __call__(self, x):
        self.out = torch.tanh(x)
        return self.out

    def parameters(self):
        return []                     # 没有参数


# ---------------- 数据 ----------------
words = open('names.txt', 'r').read().splitlines()
chars = sorted(list(set(''.join(words))))
stoi = {s: i + 1 for i, s in enumerate(chars)}
stoi['.'] = 0
itos = {i: s for s, i in stoi.items()}

block_size = 3
X, Y = [], []
for w in words:
    ctx = [0] * block_size
    for ch in w + '.':
        ix = stoi[ch]
        X.append(ctx[:])
        Y.append(ix)
        ctx = ctx[1:] + [ix]
X, Y = torch.tensor(X), torch.tensor(Y)

# ---------------- 组装 ----------------
n_embd, n_hidden = 10, 100
C = torch.randn((27, n_embd), generator=g)

layers = [
    Linear(n_embd * block_size, n_hidden), BatchNorm1d(n_hidden), Tanh(),
    Linear(n_hidden, 27),
]

# 每个层自己报告参数，拼成一个大列表 (这就是 model.parameters() 的原理)
params = [C] + [p for layer in layers for p in layer.parameters()]
for p in params:
    p.requires_grad = True

# ---------------- 训练 ----------------
for i in range(5000):
    ix = torch.randint(0, X.shape[0], (64,), generator=g)

    emb = C[X[ix]]                              # 查表 (64, 3, 10)
    x = emb.view(emb.shape[0], -1)              # 拼成 (64, 30)
    for layer in layers:                        # 关键就这一行
        x = layer(x)
    loss = F.cross_entropy(x, Y[ix])

    for p in params:
        p.grad = None
    loss.backward()

    lr = 0.1 if i < 4000 else 0.01
    for p in params:
        p.data += -lr * p.grad

    if i % 500 == 0:
        print(i, f'{loss.item():.4f}')

# 实测输出（本机 torch 2.14 +cpu，2 线程）：
#     0     3.4454
#     1000  2.5088
#     2000  2.1360
#     3000  2.2366
#     4000  2.1430
# loss 从 3.4 掉到 2.14 附近，就说明骨架写对了。


------------------------------------------------------------
四、和 Karpathy 原版比，这里删掉了什么（都可以忘）
------------------------------------------------------------

  bias / bias=False 判断       BN 前面不用偏置，因为它会被减均值抹掉
  training 分支               推理时才需要，这里只做训练
  running_mean / running_var  推理用的累积统计量
  eps / momentum 参数化       写死 1e-5 和默认值就够
  gamma *= 0.1 那段           解决"初始过度自信"的单次技巧
  isinstance 循环            用来只挑 Linear 改权重
  5 层还是 10 层              列表里的数字，随便改
  x.view 之前的 unbind+cat    教学演示慢，view 才是实际写法

删掉这么多，骨架还在，而且能跑。

------------------------------------------------------------

不是"能不能默写",而是"能不能自己从头搭一个类似的东西"。

具体做法：哪天有空，打开空文件，不看这份文件，
